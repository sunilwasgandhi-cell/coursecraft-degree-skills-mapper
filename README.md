# CMRU School of Design showcase

A responsive, browser-based showcase page for projects, assignment prompts, and achievements across the six CMR University School of Design programmes.

## Run it

Open `index.html` in a modern browser. No build step or package installation is needed.

## Page sections

- School introduction and CMRU School of Design logo.
- Programme directory: Product Design, Interior Design, Fashion Design, Communication Design, BSc in Sound Engineering, and BSc in Visual Effect and Animation.
- Filterable studio showcase with sample assignment prompts for each discipline.
- Assignment introduction and achievement categories for awards, exhibitions, collaborations, and impact.
- Responsive navigation and programme filters.

The assignment prompts are illustrative. Replace them with approved student work, images, names, dates, and verified achievements before publishing the page as a factual showcase.
